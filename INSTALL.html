OS READING GUIDE · WINDOWS / CHROME

教材を開けば、すぐに解説。

194項目の保存済み解説は通信せずに読めます。新しい解説は、ChatGPT Plusの対象利用枠で作成できます。APIキーは使いません。

GitHubから取得したソースでは、最初にリポジトリのルートで npm run build を実行してください。Node.js 22以上が必要です。

1. 拡張機能を読み込む

  1. ZIPの場合は右クリック→「すべて展開」。展開したフォルダーは今後も使う場所に置いてください。
  2. 既に使用中なら、先に「読書ガイド」→「JSONを書き出す」で個人辞書をバックアップします。既存の拡張を削除しないでください。同じフォルダーのファイルを更新し、次の画面で再読み込みすればデータを維持できます。
  3. Chromeのアドレス欄に chrome://extensions と入力し、右上の「デベロッパー モード」をオン。
  4. 初回は「パッケージ化されていない拡張機能を読み込む」→この配布物のextensionフォルダーを選択。更新時は既存の「OS読書ガイド」の丸い矢印（再読み込み）を押します。
  5. 第9章「メモリ割り当て」を開きます。既に開いている場合はCtrl＋R。「読書ガイド」と本文の点線を確認します。

2. Windows補助プログラムを登録する

1.4.5：接続名が文字化けする場合もsetup-helper.cmdを実行し、AI設定をCtrl＋Rで更新してください。日本語の受け渡しを修正します。再ログインは不要です。

1.4.4へ更新するとき

同じextensionフォルダーを更新し、このWindows上でsetup-helper.cmdを実行します。新しい接続名jp.osreadingguide.chatgpt.v2と、互換用の旧登録を設定します。AI設定の「接続診断」で画面・バックグラウンド・補助のバージョンと「接続先 v2」を確認できます。

画面だけ新しく「Chrome登録」が旧版なら、入力中の内容を保存してChrome全体を再起動します。現行補助へ接続できても未ログインの場合は、「ChatGPTアカウントを切り替える」から希望するアカウント・ワークスペースで認証します。辞書の削除や認証ファイルの初期化は不要です。

簡単な初回登録・復旧（1.3.1）

手順1でChromeへextensionを読み込んだ後、この配布フォルダーの setup-helper.cmd をダブルクリックしてください。現在のフォルダーの拡張IDを自動検出し、Windowsの登録を検査・更新します。管理者権限・既存アカウントの再ログインは不要です。自動検出できなければ拡張IDを入力します。以下の手動コマンドも利用できます。

完了後はAI設定の「接続を再確認」。辞書や認証情報は削除しません。

保存済み解説を読むだけなら、この手順以降は不要です。AI生成に使う補助プログラムは、必要時にChromeが起動します。

  1. 拡張一覧の「OS読書ガイド」に表示されるID（32文字）をコピーします。「読書ガイド」→「AI設定」にも表示されます。
  2. この配布物のフォルダーをエクスプローラーで開き、上のアドレス欄に powershell と入力してEnter。
  3. 開いた画面に、次のコマンドを貼ります。IDをここへをコピーした32文字に置き換えてEnterを押してください。
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-helper.ps1 -ExtensionId IDをここへ

「補助プログラムを登録しました」と表示されれば完了です。管理者権限は不要です。実行ポリシーの変更はこのコマンドだけに適用されます。

Node.js 22以上が必要です。Node.jsの配置を自動検出します。見つからない場合は Node.js公式サイトで22以上をインストールして再実行するか、コマンドの最後に -NodePath "node.exeのフルパス" を付けます。検出したnode.exeは補助プログラム用フォルダーへコピーするため、通常利用で毎回Node.jsを操作する必要はありません。

3. ChatGPTにログインする

  1. 教材の「読書ガイド」→「AI設定」→「接続を再確認」。
  2. Continue with ChatGPTを押し、開いたOpenAI公式画面でPlusのアカウントにログイン。OS Reading GuideのChatGPTプラン利用を許可します。
  3. AI設定に戻り、ログイン完了を確認。「ChatGPTの利用状況・アプリの利用制限を管理」を開き、このアプリのクレジット利用をOFFにします。
  4. AI設定で利用モデルを選び、プラン利用とクレジットOFFの確認欄をチェックして設定を保存。
Plusの利用上限は連携アプリ間で共有されます。上限に達したら回復を待ちます。有料APIへの切替はありません。ChatGPT側でクレジット使用を許可するとその残高が使われ得るため、必ずOFFにしてください。この設定は拡張から自動確認できません。

4. 解説を読む・追加する

  • 点線の表現にホバー→短い説明。クリック→固定。「詳しい説明を読む」で展開。
  • 解説内の点線から別の解説へ。「← 戻る」と道順で戻れます。
  • 元のリンクは普通にクリックすると移動します。リンクの解説を固定するにはAlt＋クリック、キーボードならAlt＋Enter。
  • 未登録の表現を選択→「選択から解説を追加」。または「読書ガイド」→「解説を追加」で文字列を入力。「生成に送る文脈を確認」を見て「解説を生成・追加」。
  • 生成が完了すると辞書に保存され、再読み込みなしで本文・コードに反映します。「この解説を編集」「この解説を削除」で管理できます。

解説を一覧から探す

Chromeの拡張アイコンをクリック、または教材の「読書ガイド」→「解説辞書を開く」で独立した辞書ページを開けます。検索は説明本文にも対応し、初期搭載・自分で追加・個人編集の絞り込み、並べ替え、追加・編集・削除ができます。変更は教材のポップアップにも自動反映します。「教材で読む」の章リンクから、該当箇所へ移動できます。

1.2への更新では、chrome://extensionsでこの拡張の再読み込みを押し、教材をCtrl＋Rしてください。補助プログラムの再インストールや再ログインは不要です。

1.3の更新：詳しい解説と図解

概要の下の「詳しい説明を読む」で、背景や具体例まで確認できます。図がある項目では「図を文章で読む」も使えます。個人編集した解説は維持されます。新しい初期説明へ戻したい場合だけ、辞書でその項目の「個人編集を解除」を選んでください。

同じフォルダーを使用している場合、Chromeの chrome://extensions でこの拡張の再読み込みボタンを押し、開いていた教材と辞書のタブも再読み込みしてください。別フォルダーの拡張を読み込んでいる場合は、新しい作業フォルダーのextensionを使用しているか確認してください。今後のAI生成指示を更新するには、未更新の補助プログラムだけ手順2で更新します。既存のログインと設定は維持され、再認証は不要です。

アカウントの切り替え（1.4）

別のChatGPTアカウントやワークスペースを使うときは、AI設定の「ChatGPTアカウントを切り替える」で新しい登録を追加します。保存済みの接続から以前の登録へ戻ることもできます。Continue with ChatGPTは同じ登録の再認証用です。辞書や図は消えません。接続を切り替えるたび、アカウント・モデル・その接続のクレジット利用OFFを確認して設定を保存します。新しい接続のOFFが未確認なら生成を有効にしないでください。補助プログラムはsetup-helper.cmdで更新できます。

困ったとき

  • 補助プログラムに接続できない：現在の拡張IDで手順2を再実行。フォルダーを変えて拡張を入れ直すとIDが変わる場合があります。
  • 認証画面が出ない：AI設定を開き直して再試行。認証は最大4分待機します。
  • 認証期限・許可のエラー：Continue with ChatGPTから再ログイン。
  • 生成の途中で切れた：不完全な結果は保存しません。接続・利用枠を確認してから再試行。
  • 表示されない：Chrome拡張を再読み込みしてから教材をCtrl＋R。対象は日本語版です。
  • 別PCへ移す：個人辞書をJSONで書き出して読み込み。Windowsの暗号化認証情報はコピーせず、新しいPCでログインします。

更新・削除

更新時は同じextensionフォルダーを更新し、拡張を再読み込み。補助プログラムも手順2で更新できます。使用中の補助プログラムでファイルがロックされた場合はAI設定タブを閉じて再試行してください。

削除時は先に辞書をJSONで保存し、AI設定でログアウト。scripts\uninstall-helper.ps1 を実行するとChromeとの接続登録を解除します。認証の取り消しを確認できなかった場合は、ChatGPT設定でもOS Reading Guideを切断してください。保存先は %LOCALAPPDATA%\OSReadingGuide です。
