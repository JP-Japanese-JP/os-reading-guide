# B追加改善だけを戻すパッケージ

このパッケージは、前回のA改善を含む未コミット変更を保持してBだけを取り消すためのものです。コミットやGit履歴には依存しません。

リポジトリのルートで実行：

```powershell
python rollback/b-followup/restore.py --check
# Bを取り消すと決めたときだけ：
python rollback/b-followup/restore.py --apply
```

最初のコマンドは検査のみ。ハッシュ比較ではGitのチェックアウト設定による改行形式の差を無視します。--applyも全ファイルの現在のハッシュと復元ファイルを照合してから処理し、後続編集があれば一切書き換えず停止します。その場合、パッケージを無理に書き換えず差分を確認してください。

before/はA状態の復元ファイル、b-only.diffはBのレビュー用差分、manifest.jsonは対象とハッシュです。解説2ファイルは開始時保存データに基づきます。表示処理・テストは小さな変更を逆適用し、対応記録は保存データと前回監査成果物を使ってA状態を再構成しました。全ファイルのバイト完全一致を保証するバックアップではなく、Aの内容と動作への復元です。

B新設ファイルは削除せずarchived-b/へ退避します。既存ファイルのB版もそこへコピーして残します。図の生成物はnpm相当のビルドでA版へ戻します。実ユーザーの個人データ、教材原稿、Git履歴は操作しません。画像とこのパッケージは残ります。

別フォルダで--applyとビルドを試し、Aの194件・26図・69件改善・参照先・前提DAGを確認した結果をverification.jsonに保存しています。本番作業フォルダではBを適用した状態を維持しています。
